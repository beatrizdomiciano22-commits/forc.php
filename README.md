# forca.php
# Este projeto consiste num Jogo da Forca clássico, desenvolvido para ambiente web através da integração de três tecnologias fundamentais do ecossistema front-end: HTML5, CSS3 e JavaScript (ES6). O objetivo principal do jogo é adivinhar uma palavra secreta oculta, selecionando uma letra de cada vez antes que as tentativas (vidas) se esgotem.
